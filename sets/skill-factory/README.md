# Skill Factory

**Purpose:** help skill authors turn a repeatable capability into a portable skill, test whether it activates and improves outcomes, and release a reviewed set snapshot.

## Members

| Skill | Use it when |
| --- | --- |
| [`author-skills`](skills/author-skills/SKILL.md) | Designing or writing an Agent Skills-format skill. |
| [`evaluate-skills`](skills/evaluate-skills/SKILL.md) | Creating or reviewing behavioral evaluation cases and results. |
| [`release-skill-sets`](skills/release-skill-sets/SKILL.md) | Preparing a versioned, evaluated set for distribution. |

**Version:** `0.1.0` (pre-release)

**License:** Apache-2.0

**Supported runtime:** OpenCode. It is not yet listed as tested; live evaluation execution is not yet configured. See the repository [evaluation protocol](../../docs/evaluation.md).
