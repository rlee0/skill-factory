# Monarch Money General Glossary

This file contains reusable terminology only. It is not a connected household's category catalog, budget configuration, or record of user-confirmed meanings. Category names, groups, types, enabled/disabled flags, budget exclusions, and rollover settings are deployment-specific; inspect current authorized data and use a user-approved private glossary when available.

## Shared terms

| Term | General meaning |
| --- | --- |
| Category | A primary classification assigned to a financial record. A category can have an income, expense, or transfer type. The label alone does not establish a household's intended use. |
| Category group | A way to organize categories; it is not itself a transaction meaning. |
| Budget-excluded | A setting that omits a category from budget calculations; it does not make the associated record irrelevant. |
| Rollover | A setting for carrying unused budget forward; it is not a separate pool of cash. |
| Transfer | Movement or adjustment between accounts; do not count it as new income or spending without examining the underlying records. |
| Unclassified queue | A temporary review queue, not a final category. Ask when no available category fits. |
| Merchant normalization | Aligning merchant names only when records show the same payee. Inspect linked transactions and rules before proposing a household-wide change. |

## Use and privacy

- Do not infer a user's classification practice from category names, groups, or transaction examples.
- Keep connected household catalogs, statuses, transaction data, balances, account labels, and user-specific definitions out of this portable glossary and other packaged skill resources.
- Use an approved private glossary when the user provides one. If none is available, mark meanings uncertain and ask before a consequential classification or taxonomy change.
- A glossary describes meanings; it does not authorize changes to Monarch records. Confirm every write separately.
