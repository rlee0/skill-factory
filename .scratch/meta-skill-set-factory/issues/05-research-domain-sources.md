# 05: Research source-intensive domains

**What to build:** A domain expert can deepen a domain brief using trustworthy sources and review how evidence, provenance, and uncertainty affect the proposed skill set.

**Blocked by:** 01: Discover and approve a domain brief.

**Status:** resolved

- [x] Determine when deeper research is warranted and define a focused research question before gathering sources.
- [x] Prefer trustworthy primary sources when available; retain source details and relevant dates for claims used in skills.
- [x] Distinguish source-backed findings from user claims, interpretation, and unresolved conflicts.
- [x] Surface conflicting, stale, or unavailable evidence instead of silently resolving it.
- [x] Do not present research as legal, regulatory, clinical, or other qualified professional certification.
- [x] Include evaluation cases for source selection, provenance, uncertainty handling, and irrelevant research requests.
