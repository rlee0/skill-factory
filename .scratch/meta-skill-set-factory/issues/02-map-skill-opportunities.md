# 02: Map workflows to bounded skill opportunities

**What to build:** A domain expert can turn an approved domain brief into a prioritized set of skill opportunities with clear responsibilities and activation boundaries.

**Blocked by:** 01: Discover and approve a domain brief.

**Status:** ready-for-agent

- [ ] Identify actionable tasks and workflows that are suitable for agent skills, rather than producing a topic-only inventory.
- [ ] Define each candidate's intended triggers, nearby non-triggers, responsibilities, non-goals, and expected user outcome.
- [ ] Identify overlap, excessive breadth, low-value candidates, and missing capabilities; recommend a focused inventory.
- [ ] Prioritize candidates using user value, feasibility, risk, and available evidence.
- [ ] Include evaluation cases that check the quality and boundaries of the opportunity map.
- [ ] Keep opportunity mapping independently usable from the coordinator.
