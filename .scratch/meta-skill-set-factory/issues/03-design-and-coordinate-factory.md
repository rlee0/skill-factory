# 03: Design the set and guide the factory workflow

**What to build:** A domain expert can approve a tailored skill-set architecture and follow a coordinator through the factory's major decisions and phase handoffs.

**Blocked by:** 01: Discover and approve a domain brief; 02: Map workflows to bounded skill opportunities.

**Status:** ready-for-agent

- [ ] Define set membership, responsibilities, handoffs, runtime assumptions, and conditional capabilities from the approved brief and opportunity map.
- [ ] Prefer a lean core and include specialist capabilities only when domain, risk, tool use, or release needs justify them.
- [ ] Guide the user through scope and architecture approval before authoring or packaging begins.
- [ ] Track accepted decisions and unresolved questions through the workflow without duplicating phase-skill responsibilities.
- [ ] Allow users to enter through the coordinator or use a phase skill independently.
- [ ] Include evaluation cases for end-to-end intake, approvals, handoffs, and architecture output, as well as nearby irrelevant requests.
